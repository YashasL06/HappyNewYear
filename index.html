What this site is

This is a small practice site deployed from my laptop to an EC2 server using Git, GitHub, GitHub Actions, and Apache.

It started as a simple HTML page and slowly grew into a mini DevOps lab:

  • Amazon Linux EC2 instance hardened with SSH keys and security groups.
  • Apache serving static pages from /var/www/html.
  • Deployments automated via deploy.sh and a GitHub Actions workflow.
  • Now upgraded with a New Year meme page hosted from the same pipeline.
